## 📊 Data Flow

### Test Results Flow
1. User completes test → submits answers
2. Backend calculates score and generates AI feedback
3. Redirects to `/results/:sessionId`
4. ResultsScreen fetches complete session data
5. Displays score, AI feedback, and detailed question review

### Essay Grading Flow
1. User enters essay text on `/lat-grader`
2. Submits via POST to `/api/tests/lat/grade-essay`
3. Backend calls GPT-4 with LAT grading criteria
4. Returns structured JSON with scores and feedback
5. Frontend displays in three categorized cards

### Analytics Flow
1. User navigates to `/dashboard/analytics`
2. Fetches all completed test sessions
3. Calculates statistics and prepares chart data
4. Renders three chart types with Chart.js
5. Displays interactive visualizations

## 💡 Usage Instructions

### For Students:
1. **Take a Test:**
   - Dashboard → "Start New Test"
   - Fill in details → Generate Test
   - Answer questions → Submit

2. **View Results:**
   - After submission → Results screen
   - See score, AI feedback, question review
   - Navigate to analytics or retake test

3. **Grade an Essay:**
   - Dashboard → "LAT Essay Grader"
   - Paste essay (50-5000 chars)
   - Add optional topic
   - Click "Grade My Essay"
   - Review structured feedback

4. **Track Progress:**
   - Dashboard → "Analytics"
   - View summary statistics
   - Review score trends
   - Identify weak topics
   - Check test history

### For Developers:
1. **Install dependencies:**
   ```bash
   cd client
   npm install
   ```

2. **Start development servers:**
   ```bash
   # Terminal 1 - Server
   cd server
   npm run dev

   # Terminal 2 - Client
   cd client
   npm run dev
   ```

3. **Access application:**
   - Client: http://localhost:5173
   - Server: http://localhost:5000

4. **Test new features:**
   - Follow TESTING_GUIDE_STEPS_10_11.md
   - Complete at least 5 tests for analytics
   - Try LAT essay grader with sample essays
